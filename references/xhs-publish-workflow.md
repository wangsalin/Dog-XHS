# 小红书发布流程（必须严格遵守）

> 更新日期：2026-03-23

---

## 一、发布前准备

### 1. 检查账号
- 打开创作后台：https://creator.xiaohongshu.com
- 确认左上角账号名是否正确
- 确认内容与账号方向匹配

### 2. 选择发布方式
| 方式 | 适用场景 | 操作入口 |
|------|----------|----------|
| 文字配图 | AI生成封面 | 发布笔记 → 文字配图 |
| 上传图片 | 自有图片 | 发布笔记 → 上传图片 |

---

## 二、发布流程（文字配图）

### 步骤1：进入发布页面
```
浏览器打开：https://creator.xiaohongshu.com/publish/publish?target=image
```

### 步骤2：选择发布方式
- 点击「文字配图」

### 步骤3：输入正文（⚠️ 关键步骤！）
- 点击「文字配图」后，会出现一个文本输入框
- 在这里输入内容
- **每段输入完后按回车键换行**
- 输入完成后，点击「生成图片」

### 步骤4：检查封面
- 如果封面内容不对（文字连在一起），点击「再写一张」重新生成
- 重复直到封面文字正确显示
- 选择风格（科技/简约/几何等）
- 点击「下一步」

### 步骤5：填写标题
- 在标题框输入标题
- ≤20字
- 格式：AI日报｜xxx

### 步骤6：添加话题（可选）
- 在正文框添加话题标签
- 如：#AI #科技

### 步骤7：发布（⚠️ 谨慎！）
- **必须先让用户确认内容**
- 用户确认后再点击「发布」

---

## 三、发布流程（上传图片）

### 步骤1：进入发布页面
```
浏览器打开：https://creator.xiaohongshu.com/publish/publish?target=image
```

### 步骤2：选择发布方式
- 点击「上传图片」

### 步骤3：上传图片
- 点击上传按钮
- 选择本地图片（3:4比例）
- 尺寸：720x960起，推荐1080x1440

### 步骤4：填写标题
- 在标题框输入标题

### 步骤5：填写正文
- 在正文框输入内容

### 步骤6：添加话题
- 输入话题标签

### 步骤7：发布（⚠️ 谨慎！）
- **必须先让用户确认内容**
- 用户确认后再点击「发布」

---

## 四、发布检查清单

### 发布前
- [ ] 确认账号（左上角）
- [ ] 确认内容与账号方向匹配
- [ ] 标题 ≤20字
- [ ] 封面生成/图片上传
- [ ] 话题标签 3-5个

### 发布后
- [ ] 确认发布成功（页面跳转）
- [ ] 记录到发布日志

---

## 五、注意事项

### ⚠️ 绝对禁止
- 未经用户确认直接发布
- 发布内容与账号方向不符
- 使用错误尺寸图片

### ⚠️ 发布按钮
- 到达「发布」按钮可见处
- **必须停止，汇报给用户**
- 等待用户确认后再发布

---

## 六、内容排版规范

### 段落格式
- **必须分段**，每段之间空一行
- 用空行表示段落分隔

### 文字配图模式
- 正文内容会显示在封面图中
- **必须按段落格式输入**，否则会连在一起

### 正确示例
```
🐟 AI日报 · 2026年3月23日

🔥 国内热点

1. DeepSeek V4下周发布？
有望超越GPT-5.4

2. 7大模型混战
训练成本打骨折

🌍 国际动态

1. GPT-5.4更新
1M Token上下文

#AI #科技
```

### 错误示例（不分段 - 封面图中会连在一起！）
```
🐟 AI日报 · 2026年3月23日🔥 国内热点1. DeepSeek V4...（连在一起，无法阅读）
```

### 关键要点
- 每行首尾不要有多余空格
- 话题标签单独一行
- 数字序号后内容可换行
