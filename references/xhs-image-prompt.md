# 小红书配图与内容规范

> 更新日期：2026-03-22

---

## 一、图片尺寸规范（统一3:4！）

### 所有图片统一使用 3:4 竖版
- **比例**：3:4（竖版）
- **最小尺寸**：720x960
- **推荐尺寸**：1080x1440
- **文件大小**：最大32MB
- **格式**：PNG、JPG、JPEG、WebP

### 文字配图（推荐使用）
- 使用小红书内置"文字配图"功能
- 自动生成 3:4 竖版封面

## 三、配图设计规范

### 禁止出现
- ❌ 小红书logo
- ❌ XHS相关标识
- ❌ 其他平台logo
- ❌ 复杂背景
- ❌ 过多装饰

### 设计要求
- ✅ 简洁大字标题
- ✅ 彩色渐变背景
- ✅ emoji点缀
- ✅ 数字突出
- ✅ 底部简短描述
- ✅ 居中对齐，留白适当

## 四、通用Prompt模板

### 基础版
```
[颜色]渐变背景，简洁大字标题[内容]，emoji图标点缀，数字突出，底部简短描述，现代简约设计，无logo，3:4竖版

```

```
绿色渐变背景，大字数据突出，emoji点缀，效果对比，现代简约
```

## 六、内容结构规范

### 标题规范
- **字数**：≤20字
- **格式**：数字+关键词+情绪词
- **示例**："5个Prompt公式，让AI输出翻倍"

### 正文结构
```
[开头钩子 - 1句话制造好奇]
[核心内容 - 3段式：是什么→为什么→怎么做]
[互动引导 - 提问/投票/收藏引导]
[话题标签 - 5-8个相关话题]
```

### 话题标签
- 至少5个，最多8个
- 格式：#关键词
- 常用：#AI #ChatGPT #效率神器 #教程 #干货分享

## 七、发布流程（必须遵守）

1. **选题** → 从选题库选择
2. **内容确认** → 用户确认标题+正文
3. **配图生成** → 按本规范生成
4. **封面生成** → 最后生成封面
5. **发布** → 使用文字配图或浏览器发布
